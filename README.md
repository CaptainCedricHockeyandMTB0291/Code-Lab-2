# 🧪 Code Lab 2.0

Welcome to **Code Lab 2.0** — a growing collection of useful tools, creative experiments, browser utilities, and interactive coding projects.

This repository brings together practical everyday utilities and fun technology-inspired projects, built primarily with HTML, CSS, and JavaScript.

## What's inside?

- 📝 Productivity tools and quick notes
- ⏱️ Focus timers and task managers
- 🔐 Password generators
- 🔄 Unit converters
- 📊 Text analysis and formatting tools
- 🧰 JSON and Base64 utilities
- 🌐 Browser and device information tools
- 🔖 Custom bookmarklets
- 💻 Interactive coding experiments
- 🟢 Hacker-style visual simulations

## Project goals

- Build useful tools that solve everyday problems.
- Experiment with web development and programming.
- Create projects that work across different devices.
- Keep projects organized, documented, and easy to use.
- Continue expanding the collection with new ideas.

**Code Lab is a continuously evolving collection of practical coding projects.**
